# AI 自动交易系统 · 主屏幕版（PWA）

LIFEOS 的 AI 辅助**模拟**交易系统，个人学习用。第一阶段红线不变：
只模拟、不接真实资金、不接真实交易所 Key、没有任何真实下单接口。

## 这一版是什么

2026-11-25 所有者拍板：改成与钱在哪/生息/阅迹/人生K线图相同的形态——
纯静态 PWA，部署 GitHub Pages，添加到 iPhone 主屏幕使用，不再依赖服务器。

- **数据**：账户/持仓/订单/成交全部存本机 IndexedDB，不上传任何服务器；
  总览页可导出/导入 JSON 备份（导入整体替换，带二次确认）。
- **行情**：浏览器直连 OKX 公共接口（无需 Key），页面标注来源。
- **交易数学**：与服务器版逐项同口径——手续费 0.1%（买入含费摊薄均价）、
  市价单滑点 0.05%、已实现盈亏逐笔落账、总盈亏=已实现+未实现恒等。
  同一组数字已在服务器版实测（10000 → 全平后 10009.89），本地引擎单测复刻验证。
- **限价单**：App 打开期间由前端轮询行情触发成交；关掉 App 就没人盯盘（不假装后台运行）。
- **规则版分析**：MA/波动率/风险等级/持仓提示，本地计算，带「不构成交易信号」声明，未接大模型。
- **没有的**：机器人策略中心（需要 24 小时常驻进程，主屏幕版做不到，已下线）、
  登录（数据只在本机，无此必要）、杠杆/保证金/做空（纯现货，与服务器版一致）。

服务器版（FastAPI + 登录验证 + Docker）保留在 `serene899/ai-trading` 仓库，
Oracle 账号已注册，日后想跑机器人可切回服务器路线部署。

## 开发

```bash
npm install
npm run dev     # 本地开发（5306）
npm test        # 引擎单测（vitest + fake-indexeddb）
npm run build   # 构建到 dist（GitHub Pages 部署内容）
```

技术栈：Vue 3 + Element Plus + Dexie（IndexedDB）+ vite-plugin-pwa。
界面与交易口径源自服务器版前端，本次只换实现层（API 门面签名保持不变）。
